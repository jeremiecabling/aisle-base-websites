## Session amendments & discoveries

1. **Design source of truth**: live repo `main` @ `55ca684` — a 1,923-line
   `wedding-website.tsx` that includes Things To Do, `is_baby`, and the final copy edits.
   The HANDOFF appendix's "main @ 1a16e8b" actually describes the v0 branch; its `file:line`
   citations refer to the older 1,423-line copy and are treated as approximate.
2. **Live repo's self-hosted Cormorant Garamond TTFs are binary-corrupt** (UTF-8 mangling in
   the table directories — the deployed site was almost certainly falling back to Georgia).
   v2 ships fresh variable-font woff2 from google/fonts (OFL) instead.
3. **Toolchain**: Next `15.5.24` (maintained 15.5.x backport line; same minor the legacy repos
   ran, spec semantics unchanged) — not Next 16, deliberately, for this milestone. React 19.2,
   Tailwind v4 CSS-first, Node 22 via `.nvmrc`, pnpm pinned via `packageManager`.
4. Live `main` had grown a third gate password (`verano`) and partial EN/ES `lang` state —
   both superseded by v2 design (per-tenant single password + versioning; Q17 chrome strings).
5. Bug-list conformance is enforced structurally where possible: zod schema rejects
   entitlement/payload drift (bug 4), config loader hard-fails on `!body.ok` (bug 5), gallery
   caps validated (bug 2 class), no format sniffing anywhere (bug 1).
